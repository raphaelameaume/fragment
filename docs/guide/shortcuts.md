# Shortcuts

Fragment includes a set of **keyboard shortcuts** for easier navigation and control of sketches.

| Shortcut | Action |
|---|---|
|`Cmd/Ctrl + S`| Capture the current canvas as an image
|`Cmd/Ctrl + Shift + S`| Start or stop recording the canvas as a video.
|`r`| Reload the current sketch.
|`w`| Toggle layout edit mode.
|`Space`| Pause or resume rendering.
|`p`| Toggle Build Preview mode on or off.
