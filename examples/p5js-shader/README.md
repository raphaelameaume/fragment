# p5.js - Shader

A [p5.js](https://p5js.org) WebGL sketch that draws a full-screen shader using animated noise and a shifting color palette. The zoom range and speed controls let you adjust how the pattern pulses and evolves over time.

Based on [p5.js WebGL template](../../docs/api/templates.md)
